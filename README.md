# Configurador visual em camadas

Personalização de uniforme esportivo em tempo real: base fixa, cor dinâmica e camadas que se
recombinam sem gerar uma imagem para cada variação.

**Abrir:** https://autarktech.com.br/configurador-camadas/

## Como funciona

- Toda camada é um SVG que ocupa o mesmo retângulo. O alinhamento sai da construção, e não de
  ajuste peça por peça.
- A cor entra por variável. Dez cores em cinco modelos continuam sendo cinco desenhos, não
  cinquenta imagens.
- Um arquivo só (`index.html`, cerca de 30 KB), sem dependência e sem build. Abre na hora, até em
  conexão ruim.
- Tema claro e escuro.
